Product feature samples:
a quiet desktop workbench for text evidence

Eleven Windows desktop screens that cover every V1 feature area and the four gate-approved V2 additions, and nothing else. Each screen lists the feature IDs it implements (F… = V1, V2-… = gate-approved) and the references it borrows from (R…). The full lists are in FEATURE_BOUNDARY.md and REFERENCES.md.
